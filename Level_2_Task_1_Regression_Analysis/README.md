# Level 2 - Task 1: Regression Analysis

## Objective
Build a Linear Regression model to predict house prices using the cleaned Boston Housing dataset.

## Dataset
- cleaned_house_prediction.csv

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Steps Performed
- Loaded the cleaned dataset
- Split the data into training and testing sets
- Trained a Linear Regression model
- Predicted house prices
- Evaluated the model using MSE and R² Score
- Visualized Actual vs Predicted values
- Saved predictions to regression_predictions.csv

## Results
- Mean Squared Error (MSE): 24.2911
- R² Score: 0.6688
