## Objective
Build and evaluate machine learning classification models to predict customer churn using the Customer Churn dataset.

## Tools Used

- Python

- Pandas

- NumPy

- Scikit-learn

- Matplotlib

## Dataset

- churn_train.csv

- churn_test.csv

## Tasks Performed

- Loaded training and testing datasets.

- Preprocessed the data.

- Encoded categorical variables using LabelEncoder.

- Scaled numerical features using StandardScaler.

- Trained multiple classification models:

  - Logistic Regression

  - Decision Tree

  - Random Forest

- Evaluated each model using:

  - Accuracy

  - Precision

  - Recall

  - F1-Score

- Performed hyperparameter tuning using GridSearchCV.

- Compared model performance and selected the best model.

## Results

- Successfully trained three classification models.

- Random Forest achieved the best performance.

- GridSearchCV improved the Random Forest model by finding the optimal parameters.
